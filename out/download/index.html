Before you begin

  • Create your Nimbus account first.
  • Download and extract the client outside Program Files.
  • Run the launcher as administrator once so it can update.
  • Use only the official launcher included with the client.

System requirements

Minimum

Windows 7 or newer · 2 GB RAM
DirectX 9-compatible graphics · 5 GB free storage

Recommended

Windows 10 or newer · 4 GB RAM
Stable broadband connection

Installation steps

  1. 01 Download the client from Google Drive.
  2. 02 Extract all files to your chosen game folder.
  3. 03 Open NimbusLauncher.exe.
  4. 04 Let the launcher finish patching, then enter the realm.
