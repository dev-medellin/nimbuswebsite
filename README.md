# Nimbus Conquer Frontend

Simple multi-page Next.js frontend for a European classic Conquer Online server.

## Run

```bash
npm.cmd install
npm.cmd run dev
```

The app uses the App Router, Tailwind CSS, typed mock data, and API-ready service functions in `lib/services.ts`. Copy `.env.example` to `.env.local` when the Laravel API is ready.

Routes include home, register, login, download, wiki, shop, news, rankings, account, dynamic detail pages, sitemap, and robots metadata.

The supplied logo artwork is stored at `public/assets/nimbus-hero.png`. Replace it with approved optimized WebP artwork later if desired.
